HTML

Para estruturar um site de forma organizada, o HTML utiliza tags (etiquetas) que dividem o conteúdo em seções lógicas e compreensíveis para o navegador e para tecnologias de acessibilidade.

Abaixo estão algumas das principais tags HTML, organizadas de acordo com suas funções.

1. Estrutura básica

Todo documento HTML possui uma estrutura inicial que serve como base para a página.

  • <!DOCTYPE html> — informa ao navegador que o documento utiliza HTML5.
  • <html> — é o elemento raiz que envolve todo o documento.
  • <head> — contém informações técnicas e metadados da página.
  • <meta charset="UTF-8"> — permite a correta exibição de caracteres especiais, como acentos e o "ç".
  • <title> — define o título exibido na aba do navegador.
  • <body> — contém o conteúdo visível da página.

2. Cabeçalhos e parágrafos

Essas tags são utilizadas para organizar textos de forma hierárquica.

  • <h1> até <h6> — definem títulos e subtítulos.
  • <p> — define um parágrafo.
  • <br> — cria uma quebra de linha.
  • <hr> — cria uma separação temática entre conteúdos.

3. Formatação e ênfase de texto

  • <strong> — indica importância ou forte ênfase.
  • <b> — aplica destaque visual em negrito.
  • <em> — indica ênfase no conteúdo.
  • <i> — aplica estilo itálico ao conteúdo.

4. Links e imagens

  • <a> — cria links para outras páginas ou sites. O atributo href define o destino.
  • <img> — insere imagens. O atributo src define o arquivo e alt fornece um texto alternativo.

5. Listas e agrupadores

  • <ul> — cria uma lista não ordenada.
  • <ol> — cria uma lista ordenada.
  • <li> — representa um item de uma lista.
  • <div> — funciona como um agrupador genérico de elementos.
  • <span> — permite agrupar ou estilizar pequenos trechos de conteúdo em linha.

6. Estrutura semântica

O HTML5 possui elementos semânticos que ajudam a identificar a função de cada parte da página.

  • <header> — representa o cabeçalho de uma página ou seção.
  • <nav> — representa uma área de navegação.
  • <main> — representa o conteúdo principal da página.
  • <section> — representa uma seção temática do conteúdo.
  • <article> — representa um conteúdo independente, como um artigo.
  • <footer> — representa o rodapé de uma página ou seção.

Resumo

O HTML é responsável principalmente pela estrutura e significado do conteúdo. O CSS será utilizado posteriormente para definir aparência, cores, espaçamentos e layout.
